# Quick Notes — 快捷便签：安装与使用指南

## 当前发布状态

Quick Notes — 快捷便签仍在开发中，目前尚未发布可安装版本。请只从官方 [Releases 页面](https://github.com/GrugHan/Quick-Notes/releases) 下载，避免使用第三方重新打包文件。

正式安装包发布后，本页将同步更新具体版本号、文件名和校验值。

## 下载安装

1. 打开 [Releases](https://github.com/GrugHan/Quick-Notes/releases)。
2. 选择标记为 **Latest** 的最新稳定版本。带有 `preview`、`alpha` 或 `beta` 的版本属于测试版。
3. 在 **Assets** 中下载扩展名为 `.msix` 的安装文件。
4. 双击 `.msix`，确认发布者与仓库说明一致后点击“安装”。
5. 安装完成后，从 Windows 开始菜单打开 **Quick Notes — 快捷便签**。

如果 Windows 阻止安装，请不要关闭安全功能。先核对该版本的发行说明、SHA-256 校验值和签名说明；预览版需要额外证书时，发行说明会给出明确步骤。

## 首次使用

1. 打开应用后，点击底部的“新建当天便签”。应用不会在零点或启动时自动新建日期。
2. 在当天日期标题下直接输入内容；内容会自动保存到本机。
3. 历史日期默认全部展开。点击当前日期标题可折叠或重新展开当天内容。
4. 移动或调整窗口大小后，应用会记住上次位置和状态。

## 底部工具栏

- **新建当天便签**：插入当前日期区块。
- **加粗**：加粗选中文字；快捷键为 `Ctrl+B`。
- **放大/缩小字体**：调整当前文字字号。
- **待办方框**：插入可勾选任务；快捷键为 `Ctrl+Enter`。
- **撤销/重做**：撤销或恢复最近编辑。

## 使用待办任务

1. 点击“待办方框”后输入任务内容。
2. 完成时勾选方框；任务保留在原位置，并显示删除线。
3. 鼠标停留在已完成任务上三秒，会显示创建时间和完成时间。
4. 取消勾选后，删除线和完成时间提示立即取消。

## 展开与收缩

正式版本支持将窗口收缩为始终置顶的细小横条：

- 鼠标移入横条时自动展开。
- 鼠标移出后延迟收回，防止误触。
- 默认全局快捷键 `Ctrl+Alt+N` 用于展开或收缩，可在设置中修改。
- 应用会保留滚动位置和窗口状态。

## 开机启动与外观

设置页面可选择是否随 Windows 登录启动；默认关闭。还可以调整字体大小、浅色/深色主题和全局快捷键。

## OneDrive 同步

OneDrive 同步是可选功能：

1. 在设置中选择“连接 OneDrive”。
2. 使用 Microsoft 帐户完成授权。
3. 应用仅访问 OneDrive 的应用专属目录，不浏览普通文件。
4. 离线时仍可继续记录；恢复网络后自动同步。
5. 两台设备同时修改产生冲突时，应用保留两份内容并提示处理，不会静默覆盖。

## 卸载

在 Windows“设置 → 应用 → 已安装的应用”中找到 **Quick Notes — 快捷便签**并选择卸载。卸载前如需保留内容，请先确认 OneDrive 已同步或使用版本提供的导出功能。

## 常见问题

### Releases 页面没有安装文件

说明稳定安装包尚未发布。请勿将 GitHub 自动生成的 Source code 压缩包当作 Windows 安装程序。

### 修改后立即关闭会丢失吗？

编辑会写入本地数据库；窗口关闭前还会等待未完成的保存任务结束。

### 必须登录 Microsoft 帐户吗？

不需要。本地便签离线可用；只有启用跨设备同步时才需要登录。

### 如何反馈问题？

请在 [GitHub Issues](https://github.com/GrugHan/Quick-Notes/issues) 提交 Windows 版本、应用版本、复现步骤和截图。
