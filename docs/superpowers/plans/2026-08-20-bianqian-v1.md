# Quick Notes — 快捷便签 v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Build Quick Notes — 快捷便签, an installable, single-window Windows sticky-note app with minimal rich-text editing, checkable tasks, hover-expand behaviour, and optional OneDrive sync.

**Architecture:** A .NET 8 WPF MVVM application keeps an explicit NoteDocument model in SQLite, renders it as date sections and blocks, and writes through to disk after every mutation. Window hosting, startup registration, and global hotkeys are adapter services. A Microsoft Graph client syncs an atomic JSON document to OneDrive app storage using an ETag; conflicting document versions are retained rather than overwritten.

**Tech Stack:** .NET 8; WPF; CommunityToolkit.Mvvm; Microsoft.Data.Sqlite; System.Text.Json; MSAL; Microsoft Graph HTTP API; xUnit; FluentAssertions; MSIX.

**Spec:** docs/superpowers/specs/2026-08-20-bianqian-design.md

## Global Constraints

- Support Windows 10 and Windows 11 only; ship an MSIX installer in v1.
- There is exactly one continuous note. Do not add categories, search, reminders, attachments, Markdown, or multiple-note support.
- Dates are created only through the 新建当天便签 action; never at midnight, launch, or sync.
- Date sections default to expanded and are never auto-folded.
- Sync uses only the signed-in user's OneDrive app folder (Files.ReadWrite.AppFolder); never enumerate ordinary OneDrive files.
- Offline editing and all local persistence work without Microsoft sign-in.
