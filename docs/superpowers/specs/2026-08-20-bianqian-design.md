# BianQian Windows 应用——设计规格说明

**日期：**2026-08-20  
**状态：**设计已获用户确认；待审阅后进入开发

## 1. 产品目标

BianQian 是一款可安装于 Windows 10/11 的极简桌面便签应用，用于持续记录一份个人便签。它应当随手可用而不占据桌面：完整便签可收缩为始终置顶的细小横条，鼠标移入时自动展开。

产品刻意不提供笔记本、分类、标签、提醒、日历、多便签或复杂文档功能。首要目标是快速记录与回看。

## 2. 技术与安装方式

- **界面：**基于 .NET 8 的 WPF，采用 MVVM 分离窗口行为、编辑器状态、本地存储与同步逻辑。
- **支持系统：**Windows 10 和 Windows 11。
- **安装包：**v1 使用 MSIX 安装包。
- **本地存储：**用户本地应用数据目录中的 SQLite 数据库。
- **云同步：**通过 Microsoft 帐户登录，并借助 Microsoft Graph 访问 OneDrive 的应用专属目录。应用不得枚举或访问用户普通 OneDrive 文件。同步文件受 OneDrive 帐户访问权限保护；端到端的密码加密推迟到后续版本，避免用户在第二台设备上额外处理密钥恢复。

## 3. 窗口与显示行为

### 展开后的便签

- 应用只有一个便签窗口。
- 用户可以移动和调整窗口大小；应用重启后恢复窗口位置、尺寸和上次显示状态。
- 可在设置中开启“随 Windows 启动”。默认关闭。
- 无论展开还是收缩，窗口始终置顶。
- 窗口包含一个可滚动的连续编辑区和固定在底部的操作栏。

### 收缩横条

- 收缩后，完整便签窗口变为位于原位置的细小置顶横条。
- 鼠标移入横条时自动展开；鼠标移出后，经过短暂延迟自动收缩；延迟期间重新移入则取消收缩。
- 该延迟可避免鼠标在横条与展开窗口间移动时误收起。
- 编辑区滚动位置和用户手动折叠日期块的状态，在收缩、展开及重启后均需保留。

## 4. 连续便签与日期块

- 编辑区保存为一条按时间顺序排列、由多个日期块分隔的连续内容流。
- 用户点击底部操作栏的**新建当天便签**时，插入带本地当天日期的标题，并把焦点移至其下方内容。
- 应用不得在零点、启动或同步时自动新建日期块。
- 当前及历史日期块默认全部展开；应用绝不自动折叠较早内容。
- 点击当天的日期标题可折叠或展开该日期块。折叠状态完全由用户控制，并可持续保存。

## 5. 编辑与待办任务

### 格式工具

固定在底部的操作栏仅提供：

1. 新建当天便签
2. 加粗
3. 放大字体
4. 缩小字体
5. 插入待办方框
6. 撤销
7. 重做

格式应用于当前选区或输入光标所在位置。v1 的行内展示只支持普通文本、加粗和用户调整后的字号，刻意保持简单。

### 带方框的待办项

- 点击**插入待办方框**会在光标处插入一条待办任务。
- 勾选后的任务保留在原位置并显示删除线；取消勾选后恢复正常外观。
- 每条任务记录不可变的创建时间。首次勾选时记录完成时间；取消勾选会清除完成时间；再次勾选时更新时间。
- 鼠标在已完成任务上停留三秒后，显示紧凑浮窗，包含创建时间和完成时间。三秒内移开鼠标则不显示。

## 6. 便捷操作

- 全局快捷键：`Ctrl+Alt+N` 用于在展开与收缩间切换，可在设置中修改。
- 编辑快捷键：`Ctrl+B` 切换加粗；`Ctrl+Shift+.` 放大字体；`Ctrl+Shift+,` 缩小字体；`Ctrl+Enter` 插入待办方框。
- 一个小而非打扰性的状态指示器显示：**已保存**、**同步中**或**离线**。不得打断编辑。
- 设置中只包含：开机启动、全局快捷键、Microsoft/OneDrive 连接、同步状态、字号和浅色/深色主题切换。

## 7. 本地保存与 OneDrive 同步

- 每次编辑变动立即写入本地。离线时必须可完整使用。
- 用户完成 Microsoft 帐户授权后，后台同步服务会在线上传本地改动，并下载远端改动。
- 主要同步文件放在 OneDrive 应用专属目录中，并带有版本标识以支持冲突检测。
- 首台连接设备上传本地便签；没有本地便签的新设备下载云端便签。两端都有数据时，应用必须让用户选择保留哪一份，或明确保留两份作为冲突副本；不得静默丢弃文本。
- 通过版本标识发现并发修改时，必须保留冲突副本，并以设备名称和时间标识，而非覆盖任一版本。状态指示器报告“需要处理”。
- 退出登录只停止云同步，保留本地便签；删除任何本地数据前必须要求用户明确确认。

## 8. 异常处理

- Microsoft 登录被拒绝或令牌过期时，应用仍完全可在本地使用，并在设置中显示**离线**或**重新连接 OneDrive**。
- 网络错误采用有限次数、逐步延长间隔的重试，绝不阻塞输入或退出。
- 远端同步文件损坏或无法打开时，应在本地隔离该文件并报告；最近一次可用的本地便签必须保留。
- 数据库写入失败时，显示持续性警告，并在内存中保存编辑缓冲，直至用户能导出或重试。应用不得错误地显示为**已保存**。
- 随 Windows 启动的注册失败时，必须将该设置保持关闭，并在设置中展示清晰错误。

## 9. 验收测试

1. 在支持的 Windows 系统安装、启动、输入文本、关闭并重新打开，确认文本完全保留。
2. 收缩便签，确认只留下置顶细横条；鼠标移入后展开，且滚动位置不丢失。
3. 手动创建多个日期块；重启后确认所有块默认展开，并可手动折叠当天块。
4. 插入、勾选、取消勾选及再次勾选待办项；确认删除线及三秒悬停后显示的创建/完成时间正确。
5. 验证所有底部操作栏功能和上述键盘快捷键。
6. 开启和关闭随系统启动，确认 Windows 登录后的启动行为与保存的设置一致。
7. 在两台设备登录 OneDrive，确认普通改动能收敛；再制造并发编辑，确认任一版本都不会被静默丢失。
8. 断网后在本地编辑并重启，恢复网络后确认待同步的改动成功上传，且写作过程未被阻塞。

## 10. v1 明确不包含的功能

- 多便签、笔记本、标签、分类、搜索、提醒、通知、附件、绘图、Markdown、协作和日历视图。
- 自动创建当天日期块或自动折叠历史内容。
- 访问任意非应用专属的 OneDrive 文件。
